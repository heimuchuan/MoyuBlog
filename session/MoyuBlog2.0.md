要拿到 `.lrc` 歌词文件，按从易到难给你 4 条路：

## 1. 最省事：网上直接搜「歌名 + lrc 下载」
- 打开百度/必应搜：`歌名 歌手 lrc 下载`
- 常见站：**歌词千寻**、**liguangeci**、**千千静听歌词**等
- 点进去把歌词文本复制，保存为 `.lrc` 文件即可

## 2. 网易云客户端自动下载（标准 lrc）
- 网易云本地播放歌曲时，会自动缓存 lrc 到本地
- 路径大致在：`C:\Users\你的用户名\AppData\Local\Netease\CloudMusic\` 下的 **Cache / Lyric** 文件夹
- 网易云的是**标准 lrc**，能直接用（QQ音乐的 qrc、酷狗的 krc 是加密的，别用）

## 3. 网易云网页版 F12 抓取（最准）
1. 打开网易云网页版播放歌曲
2. 按 `F12` → Network（网络）
3. 刷新，过滤框输入 `lyric`
4. 找到那个请求，`response` 里就是纯 lrc 文本，复制存成 `.lrc`

## 4. 手动创建（一定能用）
用记事本写，格式：
```
[00:00.00]作词：方文山
[00:12.50]窗外的麻雀 在电线杆上多嘴
[00:24.80]你说这一句 很有夏天的感觉
```
另存为 → 文件名 `.lrc`，编码选 **UTF-8**，放 mp3 旁边同名即可。

---

**关键提醒**：你的 `parseLrc` 现在**只认带时间戳的行**。如果你从网上复制到的是纯歌词（没 `[00:12.50]` 这种时间）就显示不了。

所以如果你觉得逐句同步太麻烦，我建议直接帮你加「纯文本歌词降级」——这样你随便复制一段歌词存成 `.lrc` 就能显示，不用管时间戳。
